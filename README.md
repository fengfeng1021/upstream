# 上游 · upstream

> 現在的市場，一頁看懂。

給沒有背景知識的人看的財經站。打開第一眼是三行白話，不是圖表。

線上版：<https://fengfeng1021.github.io/upstream/>

## 這個站在做什麼

**首頁「現在」** — 三行白話講完現在的狀況，然後四張卡片講「錢可以放的四個地方」：
股票、債券、黃金、現金。每一張卡的閱讀順序是刻意的：這是什麼 → 現在在哪 →
**最慘的時候長什麼樣** → 有哪些標的追蹤它。把風險排在標的前面，
因為新手最常犯的錯是先看到標的就想買。

**標的分析** — 30 支標的，每一支先講跌幅再講報酬。一般網站的順序是反過來的，
而那個順序正是讓人在下跌時賣掉的原因：他買進時從沒看過這東西跌起來的樣子。

| | 最慘跌過 | 回本花了 |
|---|---|---|
| SPY（標普 500） | 51% | 4.4 年 |
| QQQ（那斯達克 100） | **81%** | **14.6 年** |
| GLD（黃金） | 43% | 8.9 年 |
| TLT（長期美債） | 48% | 還沒回本 |

這幾個數字是這一頁存在的理由。它們全部從還原月線算出來，不是抄來的。

**最新資訊** — 從鉅亨網、中央社、經濟日報、Yahoo 股市抓下來，去重後按八個主題分類。
每一類前面那句話在說「這件事為什麼會影響你的錢」。沒有摘要、沒有評論、沒有重要性排序，
點下去就是原始報導。

**四個深入工具** — 想確認上面的白話不是唬人的，可以往下挖到原始數字。

## 資料每天自動更新

`.github/workflows/refresh.yml` 每天台北時間清晨重抓一次市場資料與新聞並 commit 回來。
沒有這個排程，「最新資訊」會停在最後一次手動 build 的那一天，
而一個停在三個月前的財經站比沒有還糟——它看起來是現在的。

## 這個站不會做的事

**不會叫你買哪一支。** 在台灣，沒有投顧執照而推介個別標的是刑事責任
（投信投顧法第 107 條：五年以下有期徒刑，併科 100 萬元以上罰金）。
所以這裡只講資產類別的位置，以及每一支客觀上是什麼、過去發生過什麼。

**不會說「現在貴還是便宜」。** 第一版做了一個貴賤標籤，跑出來自相矛盾：
債券被標成「就在歷史高點附近」同時寫著「還沒回本」，黃金被標成「偏低」
但它其實在近二十年的第 97 百分位。要真的講貴賤得先假設一個「合理價」，
而那個假設就是替使用者做判斷。標籤整個拿掉，改成純事實。

**不會預測。** 沒有目標價、買賣點、支撐壓力，站上不出現任何「將會」。

**不會跟你收錢，也不接廣告。** 沒有廣告、聯盟連結、開戶連結，不收 email，
沒有會員，不接業配，沒有任何第三方請求。這個站不從使用者身上賺任何一塊錢。

## 我們拒絕了什麼

調研階段用真實資料實測了每一個候選框架，而不是只讀文獻。被實測殺掉的包括：

- **美林投資時鐘（四象限）。** 用 FRED 資料重建、加上實際發布落差，樣本外四個象限全部選錯。
  成長軸的訊號量是零（t = -0.19，符號還是反的）。而且每象限只有 25 到 55 個季度，
  最小可偵測差異比它聲稱的效果還大——它在統計上不可證偽。
- **金銅比。** 常被引用的高相關是兩條非定態序列在長期通膨下行區間的同期相關，
  不是樣本外預測力。推廣它的人後來也公開表示不再管用。
- **殖利率曲線的衰退機率。** 43 年只有大約五個可用事件，最近三次裡兩次是明確失敗
  （2022-07 到 2024-07 倒掛 25 個月沒有衰退）。n = 4 校準不出機率，所以站上只給事件表。
- **「VIX 高＝該跑」的紅色警示。** 實測把 9,146 個交易日按 VIX 水位分五等分，
  最高的那一等分後續三個月報酬是**最好的**。所以站上的 VIX 不塗紅。
- **黃金的「實質利率合理價」。** 水位關係確實崩了（R² 0.75 → 0.00），
  但變動關係完全沒崩、每個子期間符號都對。崩掉的是截距不是敏感度。
  合理價模型在過去兩年會一路喊賣，而黃金漲了六成以上。

## 資料

全部 build time 抓取、固化進 `assets/data/`、commit 進 repo。前端只讀不抓。

| 來源 | 內容 | 深度 |
|---|---|---|
| FRED 免金鑰 CSV | 23 條總經序列 | 最長 1919 起 |
| Yahoo chart v8 | 29 條資產價格月線 | 最長 1985 起 |
| 證交所 `/rwd/` | 加權指數日線、三大法人月累計 | 1999-01 起、332 個月 |
| LBMA 定盤價 | 黃金、白銀 | 1968-04 起、701 個月 |

### 四個會安靜出錯的坑，全部驗過並鎖成硬性檢查

1. **Yahoo 的 `range=max` 會靜默降頻。** `^GSPC` 用 `range=max&interval=1mo` 回 168 個點，
   間距直方圖是 `{2:1, 3:166}`——166 個**三個月**的跳格。同一支用 `period1` 回 499 個點、
   間距全是 1。筆數與起訖日期都正常，只有間距會露餡。`assertMonthly()` 把間距變成硬性檢查。
2. **期貨月線有換倉空洞。** `GC=F` 等四支的月線有 43 處兩個月跳格，改用日線自己收月才連續。
3. **ICE BofA 信用利差被鎖成三年。** `BAMLH0A0HYM2` 在免金鑰 CSV 上永遠只回最近三年，
   加 `cosd` 也無效。拿它算「20 年百分位」會算出一個其實只有三年的百分位。
   長歷史一律走 `NFCICREDIT`（1971 起）與 `BAA10Y`（1986 起）。
4. **有些序列已停止發布，但照樣回 HTTP 200。** `USALOLITONOSTSAM` 停在 2024-01、
   `USSLIND` 停在 2020-02，兩條都回格式完整的 CSV。過期守門會量最後一筆的年齡並讓 build 失敗，
   而且這道檢查本身也用一條已知停更的序列測過，確認它真的會擋。

### 交叉驗證

證交所官方的 2026-07-31 加權指數收盤是 43,119.75，
從 Yahoo `^TWII` 獨立抓到的同月值也是 43,119.75。兩條不同來源的管線對得起來。

三大法人的月累計也逐月對過官方月報表（2025-03 -465.6 十億、2026-07 -738.9 十億等五個月份全對）。

## 開發

```bash
node tools/build-snapshot.mjs    # FRED + Yahoo，含過期守門
node tools/build-taiwan.mjs      # 證交所逐月回補 + LBMA，會快取到 .cache
node tools/audit.mjs             # 機械檢查，回傳碼 1 代表有硬性違規
node tools/shot.mjs .shots --only small,laptop [--dark] <url…>
node tools/shot.mjs .shots --eval tools/probes/contrast.js --no-shot <url…>
```

純靜態，沒有 build step，`npx http-server` 或任何靜態伺服器直接開。
GSAP 3.15 從 `assets/js/vendor/` 本機載入，**不從任何第三方網域載入資源**。

設計系統與每個物件的規格見 [DESIGN.md](DESIGN.md)，產品與法規邊界見 [PRODUCT.md](PRODUCT.md)。
